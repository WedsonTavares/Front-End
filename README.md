# Resultados dos Cálculos

Este projeto é uma página web simples que exibe os resultados de alguns cálculos matemáticos e lógicos. A página é construída usando HTML, CSS e JavaScript.

## Estrutura do Projeto

- `index.html`: O arquivo HTML que estrutura a página web.
- `style.css`: O arquivo CSS que estiliza a página web.
- `script.js`: O arquivo JavaScript que contém a lógica dos cálculos e manipulação do DOM.

## Funcionalidades

1. **Valor da variável SOMA**:
   - Calcula a soma dos números de 1 a 13 e exibe o resultado.

2. **Sequência de Fibonacci**:
   - Verifica se um número pertence à sequência de Fibonacci e exibe uma mensagem indicando o resultado.

3. **Faturamento diário**:
   - Calcula e exibe o menor e maior valor de faturamento diário, além do número de dias em que o faturamento foi superior à média mensal.

4. **Percentual de faturamento por estado**:
   - Calcula e exibe o percentual de representação de cada estado dentro do valor total mensal da distribuidora.

5. **Inverter string**:
   - Inverte uma string e exibe o resultado.

## Exemplo de Uso

Ao abrir a página `index.html` no navegador, você verá os resultados dos cálculos organizados em diferentes seções:

- **Valor da variável SOMA**: Exibe o valor da soma dos números de 1 a 13.
- **Sequência de Fibonacci**: Informa se o número 21 pertence à sequência de Fibonacci.
- **Faturamento diário**: Exibe o menor e maior valor de faturamento diário e o número de dias com faturamento acima da média.
- **Percentual de faturamento por estado**: Exibe o percentual de representação de cada estado.
- **Inverter string**: Exibe a string "exemplo" invertida.
